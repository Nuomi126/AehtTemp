# AehtTemp

铝电解槽温度监测与数据展示 Unity 项目。

## 开发环境

- 团结引擎 `2022.3.38t3`
- 团结引擎版本 `1.3.3`
- Git LFS

## 克隆项目

项目包含由 Git LFS 管理的大文件，请使用 Git 和 Git LFS 完整克隆：

```powershell
git lfs install
git clone https://github.com/Nuomi126/AehtTemp.git
cd AehtTemp
git lfs pull
```

## 项目结构

- `Assets`：场景、脚本和项目资源
- `Packages`：Unity 包配置
- `ProjectSettings`：Unity 项目设置

`Library`、`Temp`、`Logs`、`obj`、IDE 配置和本地构建产物不会提交到仓库。
